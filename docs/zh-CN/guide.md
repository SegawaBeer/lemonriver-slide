# 使用指南

[English](../en/guide.md) · 简体中文 · [回到首页](../../README.zh-CN.md)

程序里侧栏的「使用指南」是同一份内容。

LemonRiver 里的幻灯片由 AI Agent 来写和改，你在浏览器里看效果、动手调。用哪个 Agent 都可以，只要它能读写你电脑上的文件。

有两种用法，按习惯选一种，也可以混着用：

- **跟 Agent 说**：在 Agent 里打字，让它新建、改每一页。适合习惯打字、想让 Agent 多干活的人。
- **在界面里改**：在 LemonRiver 里直接改文字、样式、图片和页面顺序，改不了的留评论交给 Agent。适合想自己动手、看得见改了哪里的人。

两种都要先做「准备」。

## 准备（只做一次）

1. <strong>准备一个 Agent。</strong>你平时用哪个就用哪个，能打开电脑上的文件夹、读写里面的文件就行。常见的有：
   - 国内常用：WorkBuddy、DuMate、DeepSeek Harness、Trae、千问办公、豆包、Kimi CLI 等
   - 海外常用：Claude Code、Codex、Gemini CLI、Grok、Cursor、GitHub Copilot、OpenCode 等
2. <strong>让 Agent 在 LemonRiver 的文件夹里工作。</strong>用安装包装的，文件夹在「个人文件夹 → LemonRiver」；用命令行自己建的，就是你建的那个文件夹。
   - 在终端里用的 Agent：先进到这个文件夹，再启动 Agent。
   - 有窗口的 Agent：用它的「打开文件夹」选这个文件夹。
   - 这个文件夹里已经放好了给 Agent 看的说明：怎么写幻灯片、怎么处理评论、怎么知道你正在看哪一页。大多数 Agent 会自己去读；如果它好像不知道，跟它说一句「先读这个文件夹里的 AGENTS.md」。
3. **在浏览器里打开 LemonRiver**（点程序坞或桌面上的柠檬），和 Agent 左右并排放，一边说一边看。
4. **想让 Agent 看得见页面**：在 Agent 的设置里加一个 MCP 服务，命令填 `node node_modules/@lemonriver/core/bin.js mcp`，工作目录选 LemonRiver 的文件夹。Claude Code 打开这个文件夹时会自动问你要不要启用。

Agent 怎么装、怎么登录、怎么收费，按它自己的说明来，LemonRiver 不经手。

## 用法一：跟 Agent 说

1. 打开 Agent，确认它在 LemonRiver 的文件夹里。
2. **新建**：直接说要什么，例如「做一份 Q3 经营汇报，10 页左右，给管理层看，数据如下：……」。Agent 会先问几个问题再动手。写好的演示会出现在首页，没出现就刷新一下。
3. **改某一页**：在浏览器里打开那一页，跟 Agent 说「改一下这一页：标题短一点，数字放大」。Agent 知道你正在看哪一页。也可以直接说页码：「第 3 页的柱状图换成折线图」。
4. **加页、删页、调顺序**：「在第 4 页后面加一页讲风险」「把最后两页对调」。
5. **讲稿**：「给每一页写 150 字左右的讲稿」。讲稿写进每页的「演讲备注」，播放时演讲者视图里能看到。
6. 其它常用说法：「整份换成深色、更简洁的风格」「检查一遍错字和对不上的数字」「照这张截图的版式做第 2 页」（把截图发给 Agent）。

## 用法二：在界面里改

1. **先要有一份演示**：让 Agent 写一份初稿（用法一第 2 步），或者导入别人分享的包，或者在首页把现有的演示「复制」一份来改。新工作区里自带一份「试一试」练习稿，下面每一步都能在上面练。界面里目前不能从空白页开始加文字和图片。
2. **改文字**：双击页面上的文字，直接改。
3. **改样式**：单击选中，右边「格式」面板里改字号、粗细、颜色、背景、对齐、位置和大小。按住 Shift 可以多选，⌘Z 撤销。
4. **换图片**：选中图片，点「替换图片」，从素材里选，还可以裁剪。新图片先在左侧「素材」里上传。
5. **管理页面**：左边缩略图拖动调顺序，右键可以「复制」或删除。按 B 打开「故事看板」，看整份的结构，给每一页写备注。
6. **讲稿**：直接写在「演讲备注」里。
7. **界面改不了的，留评论**：点「评论」，点一个元素或拖一个框，写下想要的改动，比如「这里换成三列卡片」「加一张同比对比表」，一次可以留很多条。写完跟 Agent 说「应用评论」（Claude Code 里也可以输入 `/apply-comments`），Agent 一条条改完，改完的评论自动消失。

## 收尾

- **自检**：在「故事看板」里点「自检」，查字太小、内容出界、文字压线、缺讲稿。
- **播放**：编辑页右上角「演示」，可以全屏；演讲者视图里有当前页、下一页、讲稿和计时。
- **导出**：PDF、PPTX（导出后文字还能改）、网页。分享和备份见下面几节。

## 常见问题

- **Agent 说写完了，浏览器里没有**：确认 Agent 打开的是 LemonRiver 的文件夹，然后刷新首页。
- **Agent 写出来的不像幻灯片，或者改错了文件**：跟它说「先读这个文件夹里的 AGENTS.md，照里面的规矩做」。
- **改坏了**：界面里的改动按 ⌘Z 撤销；大改之前先在首页「复制」一份留底；删掉的演示在回收站里留 30 天。
- **评论没生效**：评论只是记下来，要跟 Agent 说「应用评论」才会改。
