# 分享、备份和云盘

[English](../en/share-and-backup.md) · 简体中文 · [回到首页](../../README.zh-CN.md)

## 把演示分享给别人

1. 在首页演示卡片的菜单里，或者编辑页右上角，点「分享」。
2. 默认会附带一份 PDF，对方没装 LemonRiver 也能直接看。不需要的话把勾去掉，包会小很多。
3. 点「生成分享包」，等它把每一页画完。页数多的演示要等十几秒。
4. 生成好以后点「在访达里显示」，压缩包就在工作区的「shared」文件夹里。用微信、邮件、网盘把它发给对方就行。

对方收到后会看到三样东西：一份 PDF、一份「怎么打开」说明、一个「LemonRiver-files」文件夹。说明里写了没装 LemonRiver 的人怎么装。

**会分享出去什么**：演示本身、它用到的素材和主题、故事看板里的章节和备注。

**不会分享出去**：你和 Agent 的对话、你电脑上的设置。

## 收到别人发来的压缩包

1. 打开 LemonRiver 的首页。
2. 把压缩包拖进首页，或者点右上角的「导入」选它。
   - 用 Safari 下载的压缩包会被自动解开，变成一个文件夹。把这个文件夹整个拖进首页也可以。
3. 确认框里会显示每一页的缩略图、页数和是用哪个版本做的。确认是你要的，点「导入」。

> **安全提醒**演示是程序代码，导入后会在你的电脑上运行。只导入你信任的人发来的。导入前的预览只是图片，不会运行任何东西。

**同一份演示又发回来了**：如果你电脑上已经有这份演示（比如你发给同事，同事改完又发回来），确认框会告诉你改了哪几页，你可以选：

- **「另存一份」**：两份都留着，新的那份名字后面加「imported」。
- **「替换」**：用新的换掉你电脑上的，旧的移进回收站，30 天内能找回。

**导入失败常见原因**：

- **「这不是 LemonRiver 的分享包」**：对方发的可能是别的压缩包，或者下载没完成。
- **「包里的文件被改动过或者缺了」**：有人解开压缩包改了里面的文件，或者网盘下载出错。请对方重新分享一次。
- **「这个包是用更新的 LemonRiver 做的」**：先在设置里更新 LemonRiver，再导入。

## 备份

备份会把整个工作区打成一个压缩包：所有演示、素材、主题、文件夹，以及主题、语言、Agent 偏好这些设置。

1. 打开「设置 → 备份」。
2. 选一个备份位置。想自动传到云盘，就选云盘的同步文件夹（下面有各家的设置方法）；只想留在本机，用默认的「LemonRiver 备份」文件夹就行。
3. 打开「每天自动备份」：LemonRiver 开着的时候每天备份一次。也可以随时点「立即备份」。
4. 「保留最近」决定留几份，更早的会自动删掉。只删 LemonRiver 自己做的备份，你放进这个文件夹的其它文件不会动。

**备份里不包括**：你和 Agent 的对话、回收站、分享出去的压缩包、Agent 的「自动批准」开关（为了安全，换了电脑要自己再打开）。

## 从备份恢复、换电脑

1. 新电脑先装好 LemonRiver（下载地址：https://github.com/SegawaBeer/lemonriver-slide/releases/latest ），确认云盘客户端也装好并登录了，备份文件已经下载到这台电脑。
2. 打开「设置 → 备份」，点「从备份恢复…」，在列表里选一份，或者点「选择其它备份文件…」找到它。
3. 勾选要恢复的演示，点「恢复」。
   - 你电脑上同名的演示会先移进回收站，30 天内能找回。
   - 你电脑上有、备份里没有的演示不会被动。
   - 素材和你电脑上同名但内容不同时，保留你电脑上的那份。

## 把备份放到云盘

**由云盘客户端负责上传**：LemonRiver 不直接登录你的云盘账号，它只把备份写进电脑上的一个文件夹。所以先装好云盘的电脑客户端并登录。

云盘客户端有两种做法：

- **有同步文件夹的**（装好客户端后会有同步文件夹的那几家，下面逐一说明）：放进这个文件夹的文件会自动上传。直接把它选成备份位置就行，LemonRiver 能自动找到的会列在「更改」的列表里。
- **只能「自动备份某个文件夹」的**：先让 LemonRiver 备份到本机默认的「LemonRiver 备份」文件夹，再到云盘客户端里把这个文件夹加进自动备份。

第一次备份到云盘文件夹时，macOS 可能会弹窗问「是否允许访问由某某管理的文件」，点「允许」。点了「不允许」的话，到「系统设置 → 隐私与安全性 → 文件和文件夹」里重新打开。

### iCloud 云盘

1. 打开「系统设置」，点最上面你的名字，再点「iCloud」。
2. 打开「iCloud 云盘」，确认「同步此 Mac」是开着的。
3. 回到 LemonRiver「设置 → 备份 → 更改」，选「iCloud 云盘」。
4. **确认传上去了**：在访达侧栏打开「iCloud 云盘 → LemonRiver 备份」，文件旁边没有小云朵和进度圈，就是传完了。也可以在 icloud.com 上看。

- 免费的 iCloud 只有 5GB，备份一份可能就有几百 MB。空间不够时把「保留最近」调小，或者在 iCloud 里升级空间。
- 换电脑恢复时，备份文件旁边如果是一朵云，表示还没下载到这台电脑：先双击它等下载完，再去恢复。

### 百度网盘

百度网盘的电脑客户端有两种办法，任选一种：

- <strong>办法一：同步空间。</strong>在客户端里打开「同步空间」，按提示把本机一个位置设成同步目录（默认叫「BaiduSyncdisk」）。然后在 LemonRiver「设置 → 备份 → 更改」里选「百度网盘同步空间」。
   - 注意：同步空间是双向的，你在电脑上删掉的文件，网盘里也会删掉。LemonRiver 删旧备份时，网盘里的那份也会一起删。
- <strong>办法二：文件夹自动备份。</strong>LemonRiver 保持备份到本机的「LemonRiver 备份」文件夹。在百度网盘客户端里找到「自动备份」，点「添加备份文件夹」，选这个文件夹。
   - 这是单向的：电脑上删掉旧备份，网盘里的不会删，用久了要自己到网盘里清理。
   - 免费用户自动备份每月有上传流量限制（客户端里写的是每月 10G），超出后要等下个月或开会员。

**确认传上去了**：在百度网盘里打开对应的文件夹，看到最新日期的备份文件就是传完了。

### 腾讯微云

1. 装好微云的电脑客户端并登录。
2. LemonRiver 保持备份到本机的「LemonRiver 备份」文件夹。
3. 如果你的微云客户端有「自动备份」或「同步」文件夹的功能，把这个文件夹加进去。
4. 没有这个功能的话，备份完成后在 LemonRiver 里点「在访达里显示」，把最新的备份压缩包拖进微云上传。

- 微云的免费空间比较小，「保留最近」可以调成 3 份。

### Dropbox

1. 装好 Dropbox 的电脑客户端并登录，访达侧栏会出现「Dropbox」。
2. 在 LemonRiver「设置 → 备份 → 更改」里选「Dropbox」。
3. **确认传上去了**：在访达里打开「Dropbox → LemonRiver 备份」，文件旁边是绿色对勾就是传完了。

- 换电脑恢复时，文件旁边如果是一朵云，表示只在网上：先双击它等下载完，再去恢复。

### OneDrive

1. 装好 OneDrive（可以在 App Store 里搜）并登录，访达侧栏会出现「OneDrive」。
2. 在 LemonRiver「设置 → 备份 → 更改」里选「OneDrive」。公司账号和个人账号会分开列出来，选你要的那个。
3. **确认传上去了**：文件旁边没有云朵和进度标记，就是传完了；也可以在 onedrive.com 上看。

- 换电脑恢复时，处理方法见上面的说明：文件只在网上的话，先双击下载完再恢复。

### 坚果云

1. 装好坚果云的电脑客户端并登录。默认会有一个「我的坚果云」同步文件夹。
2. 在 LemonRiver「设置 → 备份 → 更改」里选「坚果云 · 我的坚果云」（或你自己建的其它同步文件夹）。
3. **确认传上去了**：在坚果云客户端里看这个文件夹的同步状态，没有待上传的文件就是传完了。

- 坚果云免费版每月上传流量有限，备份文件大的话可能一个月传不了几份。

### 其它云盘

只要云盘客户端能「把电脑上的一个文件夹自动传上去」，就能用：

- 有同步文件夹的，在「更改」里点「选择其它文件夹…」选它。
- 没有的，就用本机默认的「LemonRiver 备份」文件夹，再在云盘客户端里把这个文件夹设成自动上传。

## 云盘常见问题

- <strong>备份成功了，但云盘里没有。</strong>LemonRiver 只负责写进文件夹，上传是云盘客户端做的。看一下云盘客户端有没有开着、有没有登录、有没有暂停同步。
- <strong>云盘空间满了。</strong>把「保留最近」调小，或者清理云盘里的旧备份。备份文件的大小在「上次备份」后面能看到。
- <strong>出现了「冲突副本」之类的文件。</strong>两台电脑同时往同一个文件夹备份才会这样。每台电脑用自己的备份文件夹，或者只在一台电脑上打开自动备份。
- <strong>换电脑以后怎么恢复。</strong>见上面「从备份恢复、换电脑」。关键是先让云盘把备份文件下载到新电脑上。
- <strong>我不想用云盘。</strong>默认的「LemonRiver 备份」文件夹就在你的个人文件夹里。也可以选一个移动硬盘里的文件夹，备份前插上就行。
