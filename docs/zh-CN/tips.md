## 跟 Agent 说得更省事

- **先给材料，再提要求。** 把数据、提纲、要讲的结论一次贴给 Agent，再说给谁看、讲多久、大概几页。材料越全，返工越少。
- **一次改一页。** 在浏览器里停在那一页再说「改一下这一页」，Agent 知道你正在看哪一页，不用报页码。
- **说结果，不说做法。** 「数字要一眼看见」比「字号改成 120」更好用，Agent 会自己挑合适的办法。
- **给它看样子。** 想要某种版式，就把截图发给 Agent：「照这张截图的版式做第 2 页」。
- **一次改不完的，留评论。** 在界面里点「评论」，对着要改的地方一条条写下来，最后跟 Agent 说一句「应用评论」，它会逐条改完。
- **让它自己看一眼。** Agent 接上 MCP 服务以后（见[使用指南](guide.md)「准备」第 4 步），可以跟它说「改完截图看一下，再跑一遍自检」。

## 常用快捷键

在幻灯片编辑页：

- `B`：打开故事看板
- `E`：编辑模式，`V`：预览模式，`C`：评论模式
- `I`：打开或收起右边的面板
- `⌘Z`：撤销，`⌘⇧Z`：重做，`⌘S`：保存改动
- `F`：全屏演示，`P`：演示并打开演讲者视图
- `⌘K`：搜索，跳到任意一份幻灯片

演示时：

- `→` 或空格：下一页，`←`：上一页，`Home` / `End`：第一页 / 最后一页
- 输入页码再按 `Enter`：跳到那一页
- `O`：总览，`B`：黑屏，`W`：白屏，`L`：激光笔
- `P`：打开演讲者视图，`?`：显示所有快捷键，`Esc`：退出

## 留底和交付前

- **大改之前先复制一份。** 在首页幻灯片卡片的菜单里点「复制」，改坏了还有原样。
- **删错了去回收站。** 删掉的幻灯片在回收站里留 30 天。
- **交付前跑一遍自检。** 在故事看板里点「自检」，查字太小、内容出界、文字压线和缺讲稿。
- **发给别人用分享包。** 对方就算没装 LemonRiver，也能直接看包里的 PDF。详见[分享、备份和云盘](share-and-backup.md)。
- **打开每天备份。** 在「设置 → 备份」里选一个云盘的同步文件夹，换电脑时一键恢复。
