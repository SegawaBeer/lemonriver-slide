## Asking your agent for less rework

- **Give it the material first, then the brief.** Paste the numbers, the outline and the points you want to land in one go, then say who the deck is for, how long the talk is and roughly how many pages. The fuller the material, the fewer rounds.
- **One page at a time.** Stay on that page in the browser and say "change this page"; the agent knows which page you are looking at, so there is no page number to give.
- **Describe the result, not the method.** "The number should jump out" works better than "set the font size to 120"; the agent picks a fitting way to get there.
- **Show it what you mean.** For a particular layout, send the agent a screenshot: "lay out page 2 like this screenshot".
- **Leave comments for a batch of changes.** Click "Comment" in the app, note each change on the spot, then tell the agent "apply the comments" and it works through them one by one.
- **Let it check its own work.** Once the agent has the MCP server (step 4 of "Prepare" in the [usage guide](guide.md)), ask it to "take a screenshot after the change and run the self-check".

## Keyboard shortcuts

On a deck's editing page:

- `B`: open the story board
- `E`: edit mode, `V`: preview mode, `C`: comment mode
- `I`: show or hide the panel on the right
- `⌘Z`: undo, `⌘⇧Z`: redo, `⌘S`: save your changes
- `F`: present full screen, `P`: present with the presenter view
- `⌘K`: search and jump to any deck

While presenting:

- `→` or Space: next page, `←`: previous page, `Home` / `End`: first / last page
- Type a page number and press `Enter`: jump to that page
- `O`: overview, `B`: black screen, `W`: white screen, `L`: laser pointer
- `P`: open the presenter view, `?`: show every shortcut, `Esc`: leave

## Keep a copy, check before you hand it over

- **Duplicate before a big change.** Use "Duplicate" in the deck card's menu on the home page, so the original is still there if it goes wrong.
- **Deleted the wrong deck?** Deleted decks stay in the trash for 30 days.
- **Run the self-check before you deliver.** Click "Self-check" on the Story board to find small type, overflow, overlapping text and missing notes.
- **Send decks as share packages.** The other person can read the PDF inside even without LemonRiver. See [Sharing, backup and cloud drives](share-and-backup.md).
- **Turn on daily backups.** Pick a synced cloud drive folder in Settings → Backup, and restore everything in one step on a new computer.
